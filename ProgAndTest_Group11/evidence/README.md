# Bằng chứng nộp bài

Đề yêu cầu nộp bằng chứng về việc sử dụng công cụ và phân công nhiệm vụ.

| Thư mục | Chụp gì |
|---|---|
| `commits/` | Lịch sử commit và Pull Request trên GitHub của từng thành viên |
| `tool-usage/` | Bảng Issues (theo dõi lỗi), kết quả chạy unit test, màn hình `docker compose up` |
| `task-assignment/` | Bảng phân công (xuất từ `docs/Phan_Cong_Nhiem_Vu_Group11.xlsx`), ảnh nhóm chat chia việc |

Đặt tên ảnh: `TVx_noidung_ngay.png`, ví dụ `TV3_login-commit_22-11.png`.
