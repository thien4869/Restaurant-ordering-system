# Restaurant Ordering Management System

## 1. Project Introduction
This project focuses on analyzing, specifying, and designing a Restaurant Ordering Management System.

The system allows customers to browse menus, search for dishes, manage their cart, place orders, make payments, and track order status.

Administrators can manage dishes, users, and customer orders.

## 2. Project Objectives
- Analyze system requirements.
- Specify functional and non-functional requirements.
- Design system models and diagrams.
- Design user interfaces.
- Define system architecture and data models.
